# FSW Store

**FSW Store** é um e-commerce moderno desenvolvido com tecnologias atuais do ecossistema JavaScript. O projeto utiliza **Next.js** para o front-end, com autenticação de usuários, banco de dados PostgreSQL utilizando **Prisma**, estilização com **Tailwind CSS**, e integração com a API de pagamentos **Stripe**.

## 🛠️ Tecnologias Utilizadas

- [Next.js](https://nextjs.org/) – Framework React para aplicações web modernas
- [Prisma](https://www.prisma.io/) – ORM para trabalhar com o banco de dados PostgreSQL
- [PostgreSQL](https://www.postgresql.org/) – Banco de dados relacional
- [Tailwind CSS](https://tailwindcss.com/) – Framework de utilitários para estilização
- [Stripe](https://stripe.com/) – API para processamento de pagamentos online

## ⚙️ Funcionalidades

- Cadastro e login de usuários
- Listagem de produtos
- Carrinho de compras
- Checkout com integração Stripe
